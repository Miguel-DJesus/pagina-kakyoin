# 🌐 Sobre o projeto

Este projeto foi desenvolvido como parte de uma atividade avaliativa da disciplina de Programação Web. A proposta era criar uma página utilizando HTML e CSS, escolhendo livremente um personagem e explorando a criatividade na construção e estilização do site.

Durante o desenvolvimento, colocamos em prática os conhecimentos adquiridos nas aulas anteriores, trabalhando com elementos HTML, títulos (`h1`), imagens, cores, planos de fundo (`background`) e personalização de estilos.

## 📚 O que aprendi

- Estruturação de páginas com HTML.
- Estilização de elementos utilizando CSS.
- Personalização de cores, fontes e planos de fundo.
- Utilização de títulos, imagens e outros elementos HTML.
- Aplicação da criatividade na construção de páginas web.
- Integração entre HTML e CSS.

## 🎯 Objetivo

Praticar os fundamentos do desenvolvimento web, reforçar os conhecimentos adquiridos em aula e explorar diferentes possibilidades de criação e estilização de páginas.
